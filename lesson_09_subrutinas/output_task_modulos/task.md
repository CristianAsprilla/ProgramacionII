# Raíz cuadrada con `math`

La **biblioteca estándar** de Python trae módulos listos para usar, como `math`, `random`, `datetime` y `os`. Importarlos nos ahorra escribir funciones que ya existen y están bien probadas.

En este ejercicio vas a importar el módulo `math` y usar `math.sqrt` para calcular la raíz cuadrada de un número entero positivo `N` que llega por la entrada estándar. Imprime el resultado con **2 decimales** usando un *f-string* y el prefijo exacto `Raíz cuadrada: `.

Por ejemplo, para la entrada `16` la salida debe ser:

```
Raíz cuadrada: 4.00
```

> Tip: `f"{valor:.2f}"` formatea un número con exactamente 2 decimales.
