# Ejercicio: lista de primos hasta N

## Objetivo

Implementa `primos_hasta(n)` que retorne una lista con todos los primos menores o iguales a `n`.

## Ejemplos

```python
>>> primos_hasta(10)
[2, 3, 5, 7]

>>> primos_hasta(20)
[2, 3, 5, 7, 11, 13, 17, 19]
```

## Pistas

- Itera desde 2 hasta n.
- Si el numero es primo, agregalo a la lista.
- Podes reutilizar `es_primo()` si lo importas.

Hace clic en **Check** y verifica que los 6 tests pasen.
