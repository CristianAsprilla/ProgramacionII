# Proyecto Guiado I: Tarjeta de presentación del estudiante

Bienvenido al primer proyecto guiado del curso. Vas a construir una pequeña aplicación
que muestra una **tarjeta de presentación** con tus datos como estudiante del Bachillerato Tecnico
(Bachillerato Técnico) del colegios de Panamá.

Con este proyecto vas a poner en práctica:

- **Entrada y salida de datos** (`input` y `print` con f-strings).
- **Variables y tipos de datos** (`str`, `int`, `float`).
- **Operadores** aritméticos y de concatenación.
- La forma correcta de **organizar un programa** en funciones.

El proyecto se divide en **dos pasos**:

1. En el **primer paso**, vas a implementar una función que reciba tu nombre y
   tu edad y devuelva un saludo.
2. En el **segundo paso**, vas a ampliar el programa para que también muestre tu
   promedio de notas y la cantidad de materias que estás viendo este trimestre.

A medida que completes cada paso, tu código de la tarea anterior se mantiene
disponible para la siguiente. Esto se llama **proyecto guiado** y es una forma
sencilla de ir construyendo un programa más complejo paso a paso.

## ¿Qué construirás?

Al finalizar, tu programa se verá (más o menos) así cuando lo ejecutes:

```
========================================
   TARJETA DE PRESENTACIÓN DEL ESTUDIANTE
========================================
Nombre:           María González
Edad:             17 años
Programa:        Bachillerato Tecnico
Trimestre actual: III
Promedio de notas: 92.5
Materias inscritas: 6
========================================
¡Éxito en tu trimestre!
```

## Antes de empezar

Asegúrate de tener Python 3.10 o superior instalado. Si tu instalación imprime
una versión anterior, pídele ayuda al profesor antes de continuar.
