# Plan de localización a Panamá + expansión de prácticos

## Contexto
- Audiencia: estudiantes de 11° grado del colegios de Panamá, BTI (Bachillerato Técnico).
- Idioma base: español estándar latinoamericano (NO voseo argentino, NO leísmo ni otros regionalismos).
- Las conjugaciones imperativas y de voseo se cambian a conjugaciones de **tú** (estándar para Panamá y la mayoría de Latinoamérica).
- Los ejemplos, terminología y referencias culturales se adaptan a Panamá.

### Términos culturales y técnicos

| Argentina / genérico | Panamá | Acción |
|---|---|---|
| IVA | ITBMS | El impuesto en Panamá se llama **ITBMS** (7%). |
| nota 0-100 | nota 1.0-5.0 | **En colegio se usa escala 1.0 a 5.0**. Las universidades usan 0-100. Para contexto colegio: 5.0 es excelente, 4.0 es muy bueno, 3.0 es mínimo aprobatorio (1.0-2.9 reprueba). |
| boleto (transporte) | pasaje / ticket | "boleto" es argentino |
| colectivo | bus / autobús | "colectivo" es argentino |
| manejar (auto) | manejar (auto) | OK en Panamá también |
| carro / auto | carro | OK |
| peso argentino | balboa / dólar | Panamá usa **balboa** (igual a dólar) y dólares libremente |

### Contexto específico para el BTI Panamá

- **Escala de notas oficial**: 1.0 a 5.0, donde 3.0 es mínimo aprobatorio.
- **ITBMS**: 7% sobre el precio (no IVA).
- **Moneda**: balboa panameño (PAB) y dólar estadounidense (USD), uso indistinto.
- **Tecnología**: ya hay referencias a PyCharm, Python, JetBrains — OK.

## Distribución de trabajo

- **Agente 1** (Trim I, lecciones 1-5): localización + prácticos nuevos
- **Agente 2** (Trim II, lecciones 6-10): localización + prácticos nuevos
- **Agente 3** (Trim III, lecciones 11-15): localización + prácticos nuevos

Cada agente:
1. **Primero** arregla los regionalismos en sus archivos
2. **Segundo** adapta ejemplos a Panamá (IVA→ITBMS, escala 0-100→1-5)
3. **Tercero** agrega los prácticos nuevos listados arriba
4. **Cuarto** actualiza `lesson-info.yaml` con la nueva lista
5. **Quinto** valida YAML + tests
