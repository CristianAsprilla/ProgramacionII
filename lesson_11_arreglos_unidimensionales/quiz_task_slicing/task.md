# Quiz: rebanado (slicing) de listas

Observa el siguiente programa:

```python
notas = [4.5, 4.0, 4.8, 3.9, 5.0]
print(notas[1:3])
```

¿Qué se imprime al ejecutar el programa? Selecciona una sola opción. Recuerda que el
rebanado `lista[inicio:fin]` toma los elementos desde la posición `inicio` (incluida) hasta la
posición `fin` (excluida).
