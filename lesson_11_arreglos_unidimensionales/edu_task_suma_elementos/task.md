# Ejercicio: sumar elementos de una lista

Una operacion fundamental con listas. En esta actividad vas a implementar la suma de todos los elementos.

## Objetivo

Implementa `sumar_elementos(lista)` que retorne la suma de todos los elementos.

## Ejemplos

```python
>>> sumar_elementos([1, 2, 3, 4])
10

>>> sumar_elementos([])
0
```

## Pistas

- Usa `sum(lista)` que es built-in de Python.
- O usa un bucle `for total += elem`.
- Para lista vacia, retorna 0.
