# Reto: invertir una lista

## Objetivo

Lee numeros desde stdin (uno por linea, hasta leer "FIN") y los imprimi en orden inverso, uno por linea.

## Ejemplo

Si la entrada es:

```
1
2
3
FIN
```

La salida debe ser:

```
3
2
1
```

## Pistas

- Guarda los numeros en una lista.
- Al encontrar "FIN", sal del bucle.
- Imprime la lista en reverso: `lista[::-1]` o `lista.reverse()`.

## ¿Como probar?

Hace clic en **Check**.
