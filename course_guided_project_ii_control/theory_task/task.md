# Proyecto Guiado II: Calculadora de notas con menú

¡Hola otra vez! En este segundo proyecto guiado vas a construir una
**calculadora de notas interactiva** que se controla desde la consola.

El programa mostrará un **menú** con varias opciones y el usuario podrá elegir
qué hacer. Con este proyecto vas a poner en práctica:

- **Estructuras de control alternativas**: `if` / `elif` / `else` y `match`.
- **Estructuras repetitivas**: `while True` y `for`.
- **Funciones**: definición, parámetros y retorno.
- **Listas** como estructura de almacenamiento temporal.

## ¿Cómo se verá el programa?

```
========================================
       CALCULADORA DE NOTAS BTI
========================================
1. Agregar nota
2. Ver todas las notas
3. Calcular promedio
4. Ver nota más alta y más baja
5. Salir
========================================
Elige una opción: 1
Ingresá una nota (0-100): 95
Nota 95 agregada con éxito.

Elige una opción: 3
El promedio de las notas es: 95.0

Elige una opción: 5
¡Hasta luego!
```

## Los pasos del proyecto

El proyecto se divide en **tres pasos**:

1. **Paso 1**: implementarás las funciones para **agregar notas** y **mostrar
   la lista de notas**.
2. **Paso 2**: agregarás las funciones para **calcular el promedio** y la
   **nota más alta/baja**.
3. **Paso 3**: armarás el **menú principal** que conecta todo con un `while`
   y un `match`.

El código que escribiste en pasos anteriores se mantiene para los siguientes.

¡Empecemos!
