# Reto: volumen de una caja

## Objetivo

Lee 3 numeros (largo, ancho y alto) por stdin, uno por linea, e imprime el volumen de la caja (largo * ancho * alto).

## Ejemplo

Si la entrada es:

```
2
3
4
```

La salida debe ser:

```
24.0
```

## Pistas

- Lee con `input()` 3 veces.
- Convierte a float: `float(linea)`.
- Imprime con `print(f"{volumen}")` o similar.

## ¿Como probar?

Hace clic en **Check**.
