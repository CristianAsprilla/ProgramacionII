# Ejercicio: area de un circulo

En esta actividad vas a implementar la formula matematica del area de un circulo: `A = π * r²`.

## Objetivo

Implementa `area_circulo(radio)` que reciba el radio y retorne el area usando `math.pi`.

## Ejemplos

```python
>>> area_circulo(1)
3.141592653589793

>>> area_circulo(2)
12.566370614359172
```

## Pistas

- Importa `math` al inicio: `import math`.
- Formula: `area = math.pi * radio ** 2`.
