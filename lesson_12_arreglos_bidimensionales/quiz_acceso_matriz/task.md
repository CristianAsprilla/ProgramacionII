# Quiz: acceso con doble índice

Observa el siguiente programa:

```python
matriz = [
    [4.5, 4.0, 4.8],
    [3.9, 4.2, 4.6],
    [5.0, 4.7, 4.9],
]
print(matriz[1][2])
```

¿Qué se imprime al ejecutar el programa? Selecciona una sola opción. Recuerda que en una
matriz `matriz[fila][columna]`: el primer índice indica la fila y el segundo, la columna.
