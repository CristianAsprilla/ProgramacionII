# IA generativa de código: uso crítico

Asistentes como GitHub Copilot, Codeium, Cursor y JetBrains AI pueden sugerir código, explicar errores y proponer pruebas. Son herramientas de apoyo: pueden producir respuestas incorrectas, inseguras o incompatibles con tu proyecto. Tú seguís siendo responsable del resultado.

## Un buen prompt

Incluye: objetivo, lenguaje y versión, entradas y salidas, restricciones y ejemplos. En vez de «haz una función», pide: «En Python 3.10, crea una función que reciba una nota de 0 a 100, devuelva A–F, rechace valores inválidos y agrega pruebas para los límites».

No compartas contraseñas, tokens, datos personales de estudiantes ni código confidencial. Revisa también licencias y políticas del colegio antes de usar servicios externos.

## Verificar antes de confiar

1. Lee cada línea y explica qué hace.
2. Ejecuta casos normales, límites y entradas inválidas.
3. Compara el resultado con el enunciado y la documentación oficial.
4. Usa el depurador o mensajes temporales para localizar errores.
5. Simplifica el código y elimina dependencias innecesarias.

Si no puedes explicar una solución, todavía no está lista para entregar. La IA acelera el trabajo, pero el razonamiento, la verificación y la autoría responsable son tuyos.
