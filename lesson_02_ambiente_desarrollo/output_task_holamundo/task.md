Tu primer programa puede ser pequeño, pero te ayuda a comprobar que el intérprete está listo.

### Ejercicio

completa `main.py` para que imprima exactamente una línea:

```text
Hola, mundo
```

El programa no debe leer datos de la entrada estándar. usa `print()` y respetá las mayúsculas, la coma y el espacio de la frase. Este saludo es el equivalente a levantar la mano para comprobar que el ambiente de desarrollo funciona.
