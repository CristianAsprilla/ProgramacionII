# Quiz de escritorio: input y concatenacion

## Pregunta

Si el usuario escribe **Juan** cuando se le pide el nombre, ¿que imprime este codigo?

```python
x = input("Tu nombre: ")
print("Hola, " + x)
```

## Pista

`input()` lee una linea de texto y la retorna como string. Despues se concatena con `"Hola, "` usando `+`.
