# Quiz de escritorio: concatenacion de strings

**Prueba de escritorio**: leer el codigo y predecir que imprime. Esta es una habilidad fundamental para programar.

## Pregunta

¿Que imprime este codigo?

```python
print('Hola' + 'Mundo')
```
