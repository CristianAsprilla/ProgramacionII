# Quiz: creadores de lenguajes

En esta leccion viste que cada lenguaje de programacion tiene un creador o equipo detras. Vamos a relacionar lenguajes con sus creadores.

## Pregunta

¿Quien creo el lenguaje **C**?

## Pista

Este lenguaje fue creado en 1972 en los laboratorios Bell y dio origen a muchos lenguajes modernos como C++, Java y C#.
