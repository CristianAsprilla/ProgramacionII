# Ejercicio: suma de 1 hasta N

Una operacion clasica para practicar bucles. En esta actividad vas a sumar todos los numeros de 1 hasta N usando un bucle `for` o `while`.

## Objetivo

Implementa `suma_hasta_n(n)` que retorne la suma de los enteros de 1 hasta n.

## Ejemplos

```python
>>> suma_hasta_n(5)
15   # 1 + 2 + 3 + 4 + 5

>>> suma_hasta_n(10)
55   # 1 + 2 + ... + 10
```

## Pistas

- Usa un bucle `for i in range(1, n+1)`.
- Acumula en una variable `total`.
- Si n = 0, retorna 0 (sin entrar al bucle).

## ¿Como probar?

Hace clic en **Check** y verifica que los 5 tests pasen.
