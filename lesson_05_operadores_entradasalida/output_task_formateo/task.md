# Formateá datos con una f-string

Las f-strings permiten combinar texto y valores de variables en una sola salida legible. Vas a usar una ficha sencilla de estudiante, como las que podrías registrar para organizar las notas del curso.

## Tu tarea

lee tres líneas desde la entrada estándar, en este orden:

1. El nombre.
2. La edad como número entero.
3. La nota como número decimal.

Después imprime exactamente una línea con este formato:

```text
Nombre: Juan, Edad: 20, Nota: 4.5
```

Para la entrada del archivo de pruebas no agregues etiquetas adicionales ni líneas extra. usa una f-string para construir el mensaje.

> 📌 **Escala de notas del colegio:** usamos la escala **1.0 a 5.0**,
> donde 3.0 es el mínimo aprobatorio. Este ejercicio usa la escala del colegio.
